# Journal

New directory for the personal journal. Does not change the rest of the portfolio.

- **Live:** https://darkstone007.github.io/Portfolio/Journal/
- **Edit posts:** open [`js/posts.js`](js/posts.js) and follow the comments.
- **Add photos:** drop files in `assets/`, then list them in that posts file.

Only this GitHub account can push, so only you can post. Everyone else can view the live page.

The round tree mark is `Media/Lo.jpg` from the portfolio.
